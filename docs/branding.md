# Branding

timewarp-ci should feel like a precise developer tool with a small time-travel
spark: terminal-first, CI-aware, clean, and slightly playful.

## Assets

- `assets/logo.svg` is the default README logo for light backgrounds.
- `assets/logo-dark.svg` is available for dark surfaces.
- `assets/hero.svg` illustrates the planned v0.1 timezone matrix concept.
- `assets/terminal-demo.svg` shows the planned terminal output style.
- `assets/social-preview.svg` is sized for repository and social previews.

## Palette

| Token | Hex | Use |
| --- | --- | --- |
| Ink | `#0f172a` | Text, clock details |
| Night | `#0b1020` | Terminal and dark backgrounds |
| Pass | `#16a34a` / `#22c55e` | Passing checks |
| Fail | `#ef4444` | Failing checks |
| Sky | `#0ea5e9` / `#38bdf8` | CI and terminal accent |
| Warp | `#7c3aed` / `#a78bfa` | Time-warp accent |
