# timewarp-ci

Run project tests across time-related scenarios to catch date and timezone bugs before production.

## Installation

Installation instructions are coming soon. The package is intended to support `npx` usage.

## Usage

Early CLI seed:

```sh
timewarp-ci --help
timewarp-ci --version
```

Timezone matrix running is planned for v0.1.0.
